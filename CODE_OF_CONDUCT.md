# Community code of conduct

OffGrid Messenger welcomes contributors of varying experience. Treat other people respectfully in issues, discussions and pull requests. Give constructive, specific technical feedback; disagree about implementations without personal attacks. Harassment, threats, discriminatory abuse, doxxing, repeated hostile behavior and sharing private keys or personal information are not acceptable.

Maintainers may edit or remove abusive content, ask for a change in behavior, or restrict participation when necessary. Report conduct concerns through an appropriate private channel to the project maintainer (GitHub profile/contact method), not by publishing someone's personal information. Do not use vulnerability reporting to harass other participants.

Code review should favor reproducible evidence and documented tradeoffs over status or popularity. A contributor is never expected to make unverified range, security or safety claims to have their work considered.
