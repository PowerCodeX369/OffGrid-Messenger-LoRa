# Support and getting help

- **Setup and use:** start at the [root README](README.md), [hardware guide](docs/HARDWARE_SETUP.md), the [Android](android/README.md) or [web](web/README.md) instructions and [troubleshooting](docs/TROUBLESHOOTING.md).
- **Bug reports:** open a GitHub issue using the bug template after searching for existing reports. Include the commit/tag, platform, hardware and sanitized reproducer. Do not report application delivery from an RF ACK alone.
- **Feature requests:** use the feature-request template. Explain hardware/compatibility/security implications and whether this is beyond the feature-complete v3.0.6 scope.
- **Security issues:** follow [private disclosure](SECURITY.md), not public issue comments.
- **Contribute:** see [CONTRIBUTING.md](CONTRIBUTING.md) and the [development guide](docs/DEVELOPMENT.md).

Community support is best-effort. This software is not a substitute for emergency communications; no official support SLA, binary distribution or guaranteed RF distance is advertised. You are responsible for legal radio operation in your location.
